# LLM OCR Check Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an `ocr-check` pipeline step (and a per-block button) where the loaded vision LLM compares each block's OCR text with its crop and fixes misread characters, keeping the original OCR text for a badge and revert.

**Architecture:** A pure module `koharu-app/src/ocr_check.rs` holds the prompt, reply guard and op builder; a thin engine `pipeline/engines/llm_ocr_check.rs` crops, calls `llm::Model::read_image` per block and emits `Op::UpdateNode`. `TextData` gains `ocr_original`. A new ordering-only artifact `OcrChecked` runs the step before speaker guessing and translation. The UI adds a Process-menu switch, a per-block button, and a badge with revert.

**Tech Stack:** Rust (koharu-core, koharu-app), React + TypeScript (ui, orval-generated API types, vitest), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-30-ocr-check-design.md`

## Global Constraints

- Engine id `ocr-check`; artifact `Artifact::OcrChecked`, `ready()` always `true`.
- Field name: Rust `ocr_original`, JSON/TS `ocrOriginal`; `#[serde(default)]`.
- Hint list = all character names + glossary source terms, capped at 60 (`koharu_core::glossary::MAX_PROMPT_ENTRIES`).
- Reject reply when: empty; char-level Levenshtein > 50% of the longer text's char count; reply char count > 2 × original + 4.
- Crops shorter than 64 px (short side) are enlarged (same as `llm_vision_ocr`).
- The step never fails a page: no LLM → skip (`info`); read error → `warn`, keep ops made so far.
- Preference `ocrCheck` default `false`; UI copy added to `en-US/translation.json` only.
- `cargo fmt --check`, `cargo clippy -- -D warnings`, `bun lint:ui` must pass (CI lint).

## Review Focus

- A 1–2 character block (`！？`, `あ`) that the LLM turns into a different character: 1 of 1 changed is 100% → rejected; `…` → `……` (1 of 2 = 50%) → accepted. Test in Task 2.
- The LLM answers with a sentence ("The text reads: …") instead of the text: rejected by the length rule. Test in Task 2.
- A thinking model replies with `<think>…</think>` first: `read_image` must strip it like `read_images`. Covered by reusing `strip_thinking_block` in Task 3.
- Re-running OCR on a fixed block must clear the badge. Test in Task 1 (helper) — every OCR engine uses the helper.
- Checking a block twice keeps the first OCR text as `ocr_original`, and a reply equal to the current text makes no op (no history noise). Test in Task 2.
